# Сайты и Telegram-боты для бизнеса

Портфолио веб-разработчика: сайты для кафе, салонов, клиник, магазинов и Telegram-боты для заказов и записи.

**Сайт:** https://feyegetsu.github.io/portfolio/

## Проекты

| Проект | Ниша | Что внутри |
|---|---|---|
| [Кофейня «Зерно»](projects/cafe/) | Общепит | Меню по категориям, бронь столика |
| [Пион & Ко](projects/florist/) | Интернет-магазин | Каталог с фильтрами и сортировкой, корзина с сохранением, оформление доставки |
| [Барбершоп BLADE](projects/barbershop/) | Красота | Онлайн-запись в 3 шага: услуга → мастер → свободный слот |
| [Стоматология «Белая линия»](projects/dental/) | Медицина | Прайс по вкладкам, квиз с расчётом стоимости лечения |
| [Фитнес-клуб PULSE](projects/fitness/) | Спорт | Расписание на неделю с записью, тарифы с переключением периода |
| [Автосервис «МоторЛайн»](projects/autoservice/) | Авто | Калькулятор стоимости ремонта, отслеживание статуса заказа |
| [Агентство «Квадрат»](projects/realty/) | Недвижимость | Каталог с фильтрами и избранным, карточка объекта, ипотечный калькулятор |
| [Taskly](projects/saas/) | IT-стартап | Канбан-доска с drag & drop (мышь и тач), расчёт тарифа по числу людей |

## Принципы

- **Без фреймворков и сборки.** Чистые HTML, CSS и JavaScript, открываются с любого хостинга.
- **Адаптив.** Каждая страница проверена на ширине телефона.
- **Доступность.** Семантическая разметка, фокус с клавиатуры, учёт `prefers-reduced-motion`.
- **Каждый демо-сайт — один файл.** Его легко взять за основу под реального клиента.

## Структура

```
index.html, styles.css, script.js   главная страница портфолио
favicon.svg, 404.html
projects/
  cafe/  florist/  barbershop/  dental/
  fitness/  autoservice/  realty/  saas/   демо-сайты
  cafe-bot/                                Telegram-бот (Python, aiogram 3)
```

## Настройка

Контакты задаются в одном месте: объект `CONFIG` в начале [`script.js`](script.js).
