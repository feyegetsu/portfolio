# Портфолио: сайты и Telegram-боты для бизнеса

Сайт-портфолио с услугами, ценами и демо-проектами.

## Проекты

| Проект | Описание | Стек |
|---|---|---|
| [Кофейня «Зерно»](projects/cafe/) | Сайт кофейни: меню с категориями, бронь столика | HTML, CSS, JS |
| [Барбершоп BLADE](projects/barbershop/) | Лендинг с онлайн-записью в 3 шага | HTML, CSS, JS |
| [Бот для кафе](projects/cafe-bot/) | Telegram-бот: меню, корзина, заказы, рассылки | Python, aiogram 3, SQLite |

## Структура

```
index.html          — главная страница портфолио
styles.css, script.js
projects/
  cafe/             — демо-сайт кофейни
  barbershop/       — демо-сайт барбершопа с записью
  cafe-bot/         — исходный код Telegram-бота
```
