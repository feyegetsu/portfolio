# Telegram-бот для кафе

Бот для приёма заказов: меню по категориям, корзина, оформление заказа, уведомление администратору и рассылки.

## Возможности

- 📋 Меню с категориями и ценами
- 🛒 Корзина: добавление, просмотр, очистка
- ✅ Оформление заказа с сохранением в базу (SQLite)
- 🔔 Заказ мгновенно приходит администратору, кнопкой «Готов» клиенту отправляется уведомление
- 📢 Рассылка всем пользователям: `/broadcast текст`

## Запуск

```bash
pip install -r requirements.txt
cp .env.example .env   # вписать токен от @BotFather и свой Telegram ID
python bot.py
```

Свой Telegram ID можно узнать у бота [@userinfobot](https://t.me/userinfobot).

## Стек

Python 3.10+, aiogram 3, SQLite
