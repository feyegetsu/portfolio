# Taskly — лендинг SaaS

**[Открыть демо →](https://feyegetsu.github.io/portfolio/projects/saas/)**

![Скриншот](../../assets/previews/saas.jpg)

**Задача.** Стартапу нужно показать продукт в действии прямо на лендинге и довести до регистрации.

**Что сделано**
- Канбан-доска на первом экране
- Тарифы с ползунком числа участников
- Отзывы, bento-сетка, FAQ

**Под капотом**
- Перетаскивание мышью (HTML5 DnD) и пальцем (touch-события)
- Вставка карточки по позиции курсора

Один HTML-файл без зависимостей. Анимации из общего [`motion.js`](../shared/motion.js).
