# Белая линия — стоматология

**[Открыть демо →](https://feyegetsu.github.io/portfolio/projects/dental/)**

![Скриншот](../../assets/previews/dental.jpg)

**Задача.** Клинике нужно снять страх «сколько это стоит» и получать больше заявок на консультацию.

**Что сделано**
- Квиз из трёх вопросов с расчётом примерной стоимости
- Прайс по направлениям без перезагрузки
- Карточки врачей и форма записи к врачу

**Под капотом**
- Квиз — маленький конечный автомат, вопросы легко менять в данных
- Медицинская оговорка в подвале

Один HTML-файл без зависимостей. Анимации из общего [`motion.js`](../shared/motion.js).
