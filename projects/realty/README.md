# Квадрат — агентство недвижимости

**[Открыть демо →](https://feyegetsu.github.io/portfolio/projects/realty/)**

![Скриншот](../../assets/previews/realty.jpg)

**Задача.** Агентству нужен каталог, где клиент быстро сужает выбор и понимает платёж по ипотеке.

**Что сделано**
- Фильтры по комнатам, цене, типу и району
- Избранное между визитами
- Карточка объекта с галереей
- Ипотечный калькулятор

**Под капотом**
- Аннуитетный платёж по банковской формуле
- Карточки открываются с клавиатуры, модалка закрывается по Esc

Один HTML-файл без зависимостей. Анимации из общего [`motion.js`](../shared/motion.js).
