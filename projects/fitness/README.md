# PULSE — фитнес-клуб

**[Открыть демо →](https://feyegetsu.github.io/portfolio/projects/fitness/)**

![Скриншот](../../assets/previews/fitness.jpg)

**Задача.** Клубу нужно, чтобы клиенты сами записывались на занятия и видели свободные места.

**Что сделано**
- Расписание на 7 дней с фильтром по типам
- Запись и отмена в один клик
- Тарифы с переключением «месяц / год»

**Под капотом**
- Расписание генерируется из данных
- Пустой фильтр показывает подсказку

Один HTML-файл без зависимостей. Анимации из общего [`motion.js`](../shared/motion.js).
