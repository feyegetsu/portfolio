# Пион & Ко — интернет-магазин цветов

**[Открыть демо →](https://feyegetsu.github.io/portfolio/projects/florist/)**

![Скриншот](../../assets/previews/florist.jpg)

**Задача.** Цветочной мастерской нужен магазин, где букет можно выбрать и оформить с телефона за минуту.

**Что сделано**
- Каталог с фильтром по категориям и сортировкой
- Выезжающая корзина с подсказкой до бесплатной доставки
- Оформление: адрес, дата и интервал доставки
- Быстрая кнопка «В корзину» на фото

**Под капотом**
- Корзина в localStorage переживает перезагрузку, без него страница тоже работает
- Закрытие корзины по Esc и клику на фон
- Учёт prefers-reduced-motion

Один HTML-файл без зависимостей. Анимации из общего [`motion.js`](../shared/motion.js).
