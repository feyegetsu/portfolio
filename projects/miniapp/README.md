# Сытый Лис — Telegram Mini App

**[Открыть демо →](https://feyegetsu.github.io/portfolio/projects/miniapp/)**

![Скриншот](../../assets/previews/miniapp.jpg)

**Задача.** Ресторану доставки нужен канал заказов без комиссии агрегаторов и без разработки мобильного приложения.

**Что сделано**
- Меню с поиском и «липкими» категориями, которые подсвечиваются при прокрутке
- Шторка товара: размер пиццы и добавки с пересчётом цены
- Корзина, доставка или самовывоз, промокод `FOX10`, бесплатная доставка от суммы
- Оформление с автоподстановкой имени из Telegram и живой статус заказа

**Под капотом**
- Цвета берутся из темы Telegram через CSS-переменные SDK (`--tg-theme-*`)
- Нативные `MainButton`, `BackButton` и `HapticFeedback`; в браузере их заменяют свои элементы
- Параметр `?embed` показывает только приложение, без описания (для превью)
- Чистый JS без сборки, один файл

Чтобы подключить к боту, укажите URL страницы в BotFather (`/newapp` или кнопка меню бота).
