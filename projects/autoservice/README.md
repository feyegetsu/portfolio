# МоторЛайн — автосервис

**[Открыть демо →](https://feyegetsu.github.io/portfolio/projects/autoservice/)**

![Скриншот](../../assets/previews/autoservice.jpg)

**Задача.** Автосервису нужно вызвать доверие: честная цена до визита и прозрачный ремонт.

**Что сделано**
- Калькулятор с коэффициентом по типу машины
- Запись на ремонт из калькулятора
- Отслеживание этапов ремонта по номеру заказа (попробуйте 1234)

**Под капотом**
- Номер заказа экранируется перед выводом
- Итог всегда приходит к точной сумме, даже в фоновой вкладке

Один HTML-файл без зависимостей. Анимации из общего [`motion.js`](../shared/motion.js).
